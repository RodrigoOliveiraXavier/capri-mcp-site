Política de Privacidade — Capri MCP

Última atualização: 5 de novembro de 2026.

O que é

Capri MCP é um mod de uso pessoal que roda apenas no computador do próprio usuário. Não existe servidor do Capri MCP: nenhum dado é enviado ao desenvolvedor.

Dados do Google acessados

Com a autorização do usuário, o mod acessa, pelas APIs oficiais do Google: eventos da Agenda (ler e, quando o usuário confirma, criar, alterar ou apagar), e-mails do Gmail (ler, criar rascunhos e, quando o usuário confirma, enviar), e arquivos do Google Drive e Google Docs (ler).

Como os dados são usados

  • Somente para responder aos pedidos que o próprio usuário faz à assistente.
  • Toda ação que altera algo (enviar e-mail, criar ou apagar evento) só acontece depois de confirmação explícita do usuário.
  • Os tokens de acesso ficam guardados apenas no computador do usuário.
  • Trechos necessários para responder a um pedido podem ser enviados ao provedor de modelo de linguagem escolhido pelo próprio usuário nas configurações do aplicativo Capri. Nada é vendido, compartilhado para publicidade ou usado para treinar modelos pelo Capri MCP.

Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions, ou desinstalando o mod, o que apaga os tokens guardados.
